# 고정지출 체크

매달 나가는 고정지출(월세, 구독료, 통신비, 보험료 등)을 등록해 두고, 결제됐는지 체크하는 개인용 모바일 웹앱(PWA)입니다.

## 기능

- **이번 달**: 이번 달에 나갈 항목을 결제일 순으로 보여주고, 동그라미를 탭하면 완료로 표시
  - 총액, 납부 완료 금액, 남은 금액과 진행률 표시
  - 결제일이 지났는데 체크하지 않은 항목은 `N일 지남`, 3일 이내는 `D-n`으로 표시
  - 체크 후 바로 `실행 취소` 가능
  - 항목을 탭하면 **그 달만** 금액을 바꿀 수 있음 (전기세처럼 매달 달라지는 금액용)
  - ‹ › 버튼으로 지난 달·다음 달 이동, 가운데 월 이름을 탭하면 이번 달로 복귀
- **항목**: 고정지출 추가·수정·삭제, 월 평균 및 연간 합계, 분류별 비율
  - 매월 / 매년(결제 월 지정) 주기
  - 결제일 `말일`(31일) 선택 시 짧은 달에는 그 달의 마지막 날로 계산
  - 시작 월 / 종료 월 설정 가능 (할부, 약정 등)
  - 자동이체 표시, 사용 안 함 처리
- **설정**: JSON 백업 파일 저장·불러오기, 전체 삭제
- 오프라인 동작, 다크 모드 지원

## 기술 구성

빌드 도구나 서버 없이 HTML/CSS/JS 파일만으로 동작합니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `styles.css` | 스타일 (모바일 우선, 다크 모드) |
| `app.js` | 앱 로직, 데이터는 브라우저 `localStorage`에 저장 |
| `sw.js` | 서비스 워커 (오프라인 캐시) |
| `manifest.webmanifest`, `icons/` | 홈 화면 설치용 정보와 아이콘 |

> 데이터는 **사용하는 기기의 브라우저에만** 저장됩니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에 설정 탭에서 백업 파일을 저장해 두세요.

## 배포 (GitHub Pages)

1. 이 브랜치를 `main`에 머지
2. GitHub 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 변경
3. `main`에 푸시하면 `.github/workflows/pages.yml`이 자동 배포
   (Actions 탭에서 `Deploy to GitHub Pages`를 수동 실행해도 됨)
4. 주소: `https://<GitHub 아이디>.github.io/<저장소 이름>/`

> 비공개 저장소에서 GitHub Pages를 쓰려면 유료 플랜이 필요합니다. 무료 계정이면 저장소를 공개로 두면 됩니다. 앱 코드만 공개되고, 입력한 지출 데이터는 각자 기기에만 저장되므로 공개되지 않습니다.

## 휴대폰에 설치

- **iPhone (Safari)**: 사이트 접속 → 공유 버튼 → **홈 화면에 추가**
- **Android (Chrome)**: 사이트 접속 → 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

## 로컬에서 실행

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 수정 후 배포할 때

`sw.js`의 `CACHE` 값(`fixed-expenses-v1`)을 올려 주세요. 서비스 워커는 온라인일 때 항상 네트워크에서 최신 파일을 먼저 가져오지만, 버전을 올리면 오래된 캐시가 확실히 정리됩니다.
