# 고정지출 체크

매달 나가는 고정지출(월세, 구독료, 통신비, 보험료 등)을 등록해 두고, 한 달에 얼마가 언제 나가는지 한눈에 보는 개인용 모바일 웹앱(PWA)입니다.

## 기능

- **이번 달**
  - 이번 달 고정지출 총액과 지난달 대비 증감, 남은 결제 금액
  - 다음 결제(가장 가까운 결제일) 표시
  - 결제일이 표시된 **달력**: 날짜를 탭하면 그날 결제만 보기
  - `다가오는 결제` / `지난 결제`로 나눠 날짜순으로 표시, 3일 이내는 `오늘`·`내일`·`D-n`
  - 항목을 탭하면 **그 달만** 금액을 바꿀 수 있음 (전기세처럼 매달 달라지는 금액용)
  - ‹ › 버튼으로 지난 달·다음 달 이동, 월 이름을 탭하면 이번 달로 복귀
- **고정지출**
  - 한 달 평균·연간 합계, 분류별 비율 막대
  - 이름을 입력하면 아이콘과 색을 자동 추천 (넷플릭스 🎬, 월세 🏠 등), 직접 고를 수도 있음
  - 매월 / 매년(결제 월 지정) 주기, 결제일 `말일` 지원 (짧은 달은 그 달 마지막 날)
  - 시작 월 / 종료 월 (할부, 약정 등), 자동이체 표시, 사용 안 함 처리
- **설정**: JSON 백업 파일 저장·불러오기, 전체 삭제
- 오프라인 동작, 다크 모드 지원

## 기술 구성

빌드 도구나 서버 없이 HTML/CSS/JS 파일만으로 동작합니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `styles.css` | 스타일 (모바일 우선, 다크 모드, 웹폰트 Pretendard) |
| `app.js` | 앱 로직, 데이터는 브라우저 `localStorage`에 저장 |
| `sw.js` | 서비스 워커 (오프라인 캐시) |
| `manifest.webmanifest`, `icons/` | 홈 화면 설치용 정보와 아이콘 |

> 데이터는 **사용하는 기기의 브라우저에만** 저장됩니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에 설정 탭에서 백업 파일을 저장해 두세요.

## 배포 (GitHub Pages)

저장소 **기본 브랜치**에 푸시하면 `.github/workflows/pages.yml`이 자동으로 배포합니다.
자동으로 안 돌았으면 Actions 탭 → `Deploy to GitHub Pages` → **Run workflow**로 수동 실행하면 됩니다.

- 주소: https://geunlee00.github.io/claude_cloud/
- 처음 설정할 때: **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 두는 것을 권장

## 휴대폰에 설치

- **iPhone (Safari)**: 사이트 접속 → 공유 버튼 → **홈 화면에 추가**
- **Android (Chrome)**: 사이트 접속 → 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

## 로컬에서 실행

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 수정 후 배포할 때

`sw.js`의 `CACHE` 값(`fixed-expenses-v3`)을 올려 주세요. 서비스 워커는 온라인일 때 항상 네트워크에서 최신 파일을 먼저 가져오지만, 버전을 올리면 오래된 캐시가 확실히 정리됩니다.
